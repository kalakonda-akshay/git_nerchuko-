INTERNAL ARCHITECTURE

How Git Actually Works Under The Hood

Git is not magic—it is a content-addressable filesystem. Learn how data moves across the 4 fundamental storage zones.

ZONE 01

Working Tree

Your actual files on disk. Edits made in your editor start here as unversioned or dirty modifications before Git tracks them.

📁 Files on disk (Untracked)
ZONE 02

Staging Area (Index)

The pre-commit cache located at .git/index. It captures the exact snapshot of files intended for your next commit.

📋 .git/index (Prepared snapshot)
ZONE 03

Local Repository

The immutable object store (Blobs, Trees, Commits) stored in .git/objects. HEAD points to your current branch commit node.

🗄️ .git/objects (Commit DAG)
ZONE 04

Remote Repository

The shared cloud repository (e.g. GitHub). Tracks upstream branches like origin/main to keep distributed teams in sync.

☁️ GitHub (origin/main)

QUICK PROBLEM SOLVER

Git Emergency Decision Matrix

Stuck in a tough Git scenario? Click any real-world problem below to inspect the exact commands and rescue strategy.

⚠️ Wrong Branch

I committed to the wrong branch!

Undo the commit without losing changes, switch to the right branch, and commit there.

git reset --soft HEAD~1 git switch -c correct-branch git commit -m "fix feature"
🧹 Clean History

Squash 3 messy commits into 1

Combine multiple WIP commits into one polished atomic commit before opening a Pull Request.

git rebase -i HEAD~3 # Mark line 2 & 3 as 'squash' (or 's')
🗑️ Deleted Branch

Accidentally deleted a branch!

Git never deletes commits immediately. Find the lost commit SHA in reflog and restore it.

git reflog git switch -c recovered-branch <SHA>
🛑 Safe Public Undo

Undo a commit pushed to GitHub

Avoid force pushing to shared branches. Revert safely by appending an inverse rollback commit.

git revert HEAD git push origin main
📦 Unfinished Edits

Need to switch branches urgently

Shelve your uncommitted work temporarily without losing progress, fix the hotfix, and pop back.

git stash git switch main # do work git switch - # return & git stash pop
🎯 Surgical Commit

Grab one commit from another branch

Apply an isolated bugfix without merging the rest of an unstable experimental branch.

git cherry-pick <commit-hash>

KEY TERMINOLOGY

The Git Mental Model Glossary

Clear, authoritative definitions of the concepts every senior software engineer relies on.

📍 HEAD Pointer

A symbolic reference inside .git/HEAD pointing to the currently checked-out branch or commit. Moving HEAD changes what files are shown in your working directory.

⚡ Fast-Forward

A merge where the target branch has no divergent commits. Git simply slides the branch pointer forward to the latest commit without generating a merge commit.

👻 Detached HEAD

Occurs when you checkout an exact commit SHA instead of a branch. Edits made here are not bound to any branch and can be lost if you switch away without creating one.

📜 Git Reflog

A chronological local journal that records every single time HEAD moved (commits, checkouts, resets, rebases). It is Git’s safety net to recover lost work.

🔀 3-Way Ort Merge

The default merge engine in Git. It finds the Common Ancestor (Merge Base) of two branches and reconciles divergent edits cleanly or flags conflict markers.

📦 Interactive Rebase

Replays a sequence of commits onto a new base tip. Lets you rewrite commit messages, squash tiny WIP edits, reorder commits, or drop experiments before PR review.
